# Logs

Sample logs from a food truck scenario run. `food-truck.log` is the raw Docker Compose output; `food-truck.address-map.json` is the IP-to-service-name map captured at the time of the run. `derived-logs/` contains pretty-printed views generated by filtering and piping through `pretty-logs.py` — full logs with and without color, and personal-rep-only views with and without color. To re-derive or generate new views:

```bash
# All services, color
cat food-truck.log | python3 ../../../scripts/pretty-logs.py --color --address-map food-truck.address-map.json

# Single service (e.g. personal-rep only)
cat food-truck.log | grep '^personal-rep' | python3 ../../../scripts/pretty-logs.py --color --address-map food-truck.address-map.json
```
